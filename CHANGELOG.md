# Changelog

All notable changes to the YusufMart marketplace project are documented in this file.

- **v1.0.0 (2026-09-21)**: Full Build release implementing F1–F8 features (Authentication with BCrypt, Seller product CRUD, Buyer catalog search/filter, Shopping cart, Atomic transaction checkout, Order tracking, Admin moderation, and Reviews with star ratings).
- **v0.2.0 (2026-08-25)**: Added shopping cart, transaction-backed order placement, and seller order fulfillment workflow.
- **v0.1.0 (2026-08-10)**: MVP release featuring database schema v1, HikariCP connection pool, user registration/login with BCrypt, and product catalog browsing.
